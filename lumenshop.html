// the problem
Why agents stall the moment shopping starts.
01 · Fragmented data
Every merchant is its own schema

Scraping HTML per store means every agent prompt reinvents fields, breaks on layout change, and wastes tokens on noise.

02 · No closing mechanism
Agents stop at a product page

Without a checkout abstraction, the agent hands control back to the user at the worst possible moment — the moment of intent.

03 · Invisible performance
No attribution, no feedback loop

You cannot improve what you cannot measure. Per-agent, per-query, per-product telemetry must be first-class, not bolted on.

// your first call
Ship in five minutes. Pick your stack.
# Search the merchant graph
curl https://api.lumenshop.io/v1/search \
  -H "Authorization: Bearer $LUMEN_KEY" \
  -d '{"q":"walnut desk lamp","max_price":150}'
// ~/.config/claude/mcp.json
{
  "mcpServers": {
    "lumenshop": {
      "url": "mcp://lumenshop.io",
      "auth": { "bearer": "sk_live_..." }
    }
  }
}
from lumenshop import Client

ls = Client(api_key="sk_live_...")
results = ls.search("walnut desk lamp", max_price=150)
order   = ls.checkout.create(product=results[0].id)  # beta
import { LumenShop } from "@lumenshop/sdk";
const ls = new LumenShop({ apiKey: process.env.LUMEN_KEY! });
const hits  = await ls.search({ q: "walnut desk lamp", maxPrice: 150 });
const order = await ls.checkout.create({ product: hits[0].id });
